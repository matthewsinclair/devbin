## Problem

After `bin/devbin use` switches a tool, every open shell keeps its hashed path for the tool. From brew to dev or opt, bash and zsh still run brew's copy. From dev or opt to brew, bash gives 127, because the hashed path is gone. A PATH probe measured both. Each tool's docs now carry their own "run hash -r" line, which is one hint in many places.

## Fix

- After each switch, `use` prints one line that tells the user to run `hash -r` (`rehash` in zsh) in each open shell.
- Tools then drop their own copy of the hint at their next sweep.


## Resolution

Already fixed, with no new code (2026-11-24 12:27Z by date -u, read by devbin-cc and devbin-vc). Unit 0354-1 (5b084053, in devbin v0.1.27 onward) ends each switch that makes or removes a link with the line this issue asks for, from use_rehash_note in lib/helpers:

- a link made: "an open shell that already ran <name> still runs the copy it found before, until rehash (zsh) or hash -r (bash) is run there";
- a link removed: "an open bash that already ran <name> still looks for it at the removed link, until hash -r is run there; zsh looks again by itself".

A repointed link moves no hashed path, so nothing is said for it. devbin's own use calls it (lib/cmd/use:257 and 269), and so does a tool's use (lib/tool:454 and 461). Both of the issue's cases are covered: brew to dev or opt, and dev or opt to brew.

The six arms that prove it:

- tests/unit/use.bats: "0354-1: use dev where there was no link ends with the rehash line, and use dev over the link it made says nothing of it"
- tests/unit/use.bats: "0354-1: use opt over a dev link says nothing of rehash, use brew that removes the link ends with the hash -r line, and use brew with no link says neither"
- tests/unit/use.bats: "0354-1: use_rehash_note names each link a switch made or removed, as one list, and nothing for one it repointed or left"
- tests/unit/use.bats: "0354-1: T5 and use's page say an open shell keeps the path it first ran a command from until rehash or hash -r, and when use says so"
- tests/unit/tool.bats: "0354-1: the tool's use dev that makes its link ends with the rehash line naming it, and use opt over that link says nothing of it"
- tests/unit/tool.bats: "0354-1: the tool's use brew that removes its link ends with the hash -r line naming it"

Tools drop their own hint at their next sweep.

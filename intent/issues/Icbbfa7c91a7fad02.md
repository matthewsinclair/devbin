## Problem

The shipped lib names a machine of the fleet. lib/release.legs line 42 says "(on kovacs, zsh's ~/.zshenv)". Every project that vendors bin/.devbin/lib carries the comment, a client's tree too. A shipped file must say what the code does and name no host, person or project.

## Fix

- Reword the comment to what the code does, eg "(on a host whose zsh sets it in ~/.zshenv)".
- Add a scan arm that refuses any fleet machine name in the shipped lib, so the name cannot come back.

## Evidence

A grep of lib/ for the six fleet machine names at 0.1.30 finds this one line and no other. A peer estate reported it on hv's word.

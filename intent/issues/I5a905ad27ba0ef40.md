## What is wrong

A project whose suite must also pass under an older bash cannot run that gate through the core's lanes runner, `lib/bats-lanes` (devbin#0339). Such a gate is eg macOS's `/bin/bash` 3.2.57, which is what a project's users run. Two things stop it, both in the runner itself, not in the tests:

- `lib/bats-lanes:208` sources `lib/helpers`, whose floor check (`lib/helpers:119`, `bash_meets_floor`, then `bash_floor_refuse`) refuses any bash below 5. The runner's shebang is `#!/usr/bin/env bash`. A gate that puts `/bin` first on PATH, so that bats and every test run under 3.2, therefore starts the runner under 3.2 too, and the runner refuses before it runs a test.
- The runner's recorder times each file with `EPOCHREALTIME` (`lib/bats-lanes:180`, `:197`, `:729`, `:731`), which bash 5 has and 3.2 does not.

So the bash floor that is right for devbin's own code, the runner, also ends up applied to the shell the project's suite runs under, the tests, and the two are different things. Molt meets it today. Molt's O2 runs its suite through the lanes, and its bash 3.2 gate (`tools/test-bash32`) falls back to plain bats in one lane under `MOLT_TEST_ONE_LANE`. molt-dc found the fallback by probing the runner. Utilz has the same shape (its release gate `tools/test-estate` re-execs under `/bin` first on PATH, utilz#0051). It does not call the runner yet, but it would meet the same refusal when it does.

The fallback is correct and slow: the older-shell gate runs one test at a time on a machine with many cores, which is the cost devbin#0339 removed for every other suite.

## Fix outline

The runner names the floor it needs, for itself, apart from the shell the suite runs under, and either supports a declared older-shell gate or refuses it with the fallback named. One shape:

- The runner runs under a bash that meets devbin's floor whatever PATH says. It finds that bash the way `bash_floor_refuse`'s search does, and runs bats, and so the tests, under the PATH bash or a bash the gate declares, eg an option key or an environment variable naming the suite's shell.
- The recorder's timing stays bash 5's, since it runs in the runner, not in a test.
- Where no bash meeting the floor can be found, the runner refuses naming what it looked for, and names the one-lane fallback (plain `bats` with the project's own flags) rather than the floor alone.
- `lib/pages/test.md`'s lanes section says which shell the runner needs and which the suite runs under, and how a project declares an older-shell gate.

The plan decides the declaration's name and whether the bats under the older shell is the PATH's or a declared one, on reading Molt's `tools/test-bash32` and Utilz's `tools/test-estate`.

## Resolution

Landed at d137b5ef on main (2026-11-24 14:33Z by date -u, landed by devbin-vc). No new key: a gate puts its older bash first on PATH, and the runner finds its own.

- lib/helpers: the search for a bash at the floor is one function, bash_floor_find, with bash_floor_candidates and bash_floor_major, in the head that parses under any bash. With _DEVBIN_FLOOR_ONLY set, the head returns before the floor's check and the load guard.
- lib/bats-lanes: a runner below the floor reads the floor alone, finds a bash at the floor, and execs itself under it once, with the PATH unchanged, so bats and every test run under the gate's bash. A found bash that runs it below the floor is refused by name. With none found, it refuses and names the one-lane fallback. The recorder runs under the runner's bash, so each file is timed. The first line names both bashes.
- lib/pages/test.md says which bash the runner needs and which the suite runs under.
- A separate lib/bashfloor was built first and dropped: a vendored tree that lost it could run nothing, upgrade included.
- Arms: two in tests/unit/helpers.bats (the finder; helpers asked for the floor alone under /bin/bash) and four in tests/unit/testhandler.bats under a gate-shaped call (two lanes under /bin/bash; each file timed; the refusal naming the fallback; no second re-run). The four skip where /bin/bash meets the floor, naming what they did not check.

## Problem

The T3 manifest has no record of the checkout an opt tree was published from. A tool's dev-only refusals (eg a test or scrub verb run from an opt install) can say only "a checkout", with no path. A tool's old manifest carried this as source_tree.

## Fix (an amendment to the dev/opt/brew contract, watchout 36)

- An opt publish writes `source_tree: <absolute checkout path>` in the manifest.
- A brew publish writes none, because brew deletes its build checkout.
- Every reader treats the line as optional, so old manifests stay valid.
- An opt tree stays on its machine, so the path does not leave it.

## What happened

Ccusage's adoption of 0326 (reported by ccusage-dc, relayed by vc, 2026-11-13) found that Homebrew's build.rb (lines 232 to 236) moves metafiles (LICENSE, README, CHANGELOG and the like) out of `libexec` after install whenever the keg's root holds none. devbin's assets formula body moves the whole stage into `libexec`, so the keg's root holds none, and any metafile in a release archive leaves the manifest naming a file the keg does not hold. doctor then fails the tree row with `missing:` for each one.

## Why it matters

It affects new-form kegs too, not only the pre-contract ones in 0348: a tool cannot ship a LICENSE or README in its release archive without a brew install failing doctor. Ccusage now ships `bin/ccusage` alone to avoid it.

## Not yet known

The full list of names Homebrew treats as metafiles at the Homebrew version in use, and whether it changes between versions.

## Options, none chosen

- Have the formula body leave a metafile at the keg's root, so Homebrew moves nothing out of libexec.
- Have the manifest leave out, or the tree check pass over, files Homebrew moves, naming them.
- Have the release archive carry no metafile, and say so in the contract.

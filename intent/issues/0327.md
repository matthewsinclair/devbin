A project declares its own read-only refusals and a cut runs them before it stamps, so a refusable cut leaves no release commit behind.

## The gap

The cut's steps are pre-flight, resolve, confirm, stamp, commit, legs, tag, push, object, formula, after. A project has no seam among the first three:

- `release.gates` run in the legs step, after the commit. Pre-flight can only refuse a gate it can already tell will never run (`lib/cmd/release:2587`).
- `derived:` runs inside the stamp step (`lib/cmd/release:2754`), after version set, and a dry run skips it by design, saying so in its own unreached line (`:2738`).
- `notes.run` under `notes.kind: command` is the only pre-stamp hook, and release status, release check and the stamp's read-back all call it, so a refusal there fires on every one of those reads.
- A project `cmd/release` shadows every release verb, release gates on a remote leg included, so it is no route either.

So a project's read-only pre-stamp check becomes a post-commit gate, and when it refuses, the release commit is already made. Devbin paid that cost on 2026-11-05: 0.1.20's first cut stopped red at its legs step on seven tree-scan arms, and the release commit had to be reset (`reset --keep d1f710c0`) before the same version was re-cut.

## The ask

A declared list, `release.preflight`, of `bin/devbin <words>` lines in the gates' grammar, run in place at pre-flight by a dry run and a cut alike. Each failure joins the refusal set pre-flight already collects and fails over once (`lib/cmd/release:2622`), and a tree change one of them makes is refused as a gate's is.

A dry run must run them, since the point is that the dry run refuses wherever the cut would.

## Where it came from

Intent's ST0091 WP-01 re-inventory against the vendored 0.1.20 core, relayed by intent-vc on 2026-11-10. Intent's driver refuses a live intentd before anything is stamped, its dry run reaches that refusal, and its AC-01.3 keeps both; its first entry would be one project verb carrying that daemon check. The seam would also take back the driver's other read-only pre-stamp refusals, such as schema faces carrying the current version, which otherwise become post-commit gates.

hv ruled on 2026-11-10 that devbin's next release carries this, and that Intent's 3.3.0 waits for that release to be swept in.

## What happens

Issue 0335 found that the core reached its own `cache` verb through the project's launcher, so a project command named cache stood in for it, and fixed that verb: `core_verb` runs a verb of CORE_VERBS by its own path (lib/helpers:3743-3773), doctor fails a project command at such a name (lib/cmd/doctor:689-704), and config validation refuses a handler or run for one (lib/config:2001). CORE_VERBS holds cache alone (lib/helpers:3752).

The cut and the macOS stage still call other built-ins through `bin/devbin`, where a project handler of the same name shadows the built-in totally (lib/resolve:1039, AC-04.4):

- lib/cmd/release:3269, the stamp step: `gate_exec "$launcher" version set "$v"`.
- lib/cmd/release:3793, the formula step: `"$PROJECT_ROOT/bin/devbin" formula publish --pull`.
- lib/cmd/release:3960 and :3993, the macOS stage's publish: `macos bin-publish` and `macos publish`.
- lib/cmd/release:1377 and :2358: `ci-state --runs` and `ci-state --fires`.
- lib/cmd/macos:1549 and :1796: `release attach`, from publish and bin-publish.
- lib/cmd/macos:1820-1828, the macOS leg: `macos app-sign`, `bin-sign`, `app-notarize` and `bin-notarize`.

doctor's shadow check lists a project command at any of these names as a shadow, a note and not a failure (lib/cmd/doctor:719-730), since none is in CORE_VERBS.

## Not yet known

- Which of these a project is meant to override. Some may be meant as seams: a project with its own version scheme may own `version set`, and a project `cmd/release` shadows every release verb by design (0327's text). Others, such as `ci-state` and the macOS signing steps, read as the core's own.
- Whether any estate has a project command at one of these names today.

## Options, none chosen

- Sort each call site into the core's own, which joins CORE_VERBS, is called through core_verb and fails doctor when shadowed, or a declared seam, named in the docs as one so doctor's note is right.
- Leave the calls as they are, and say in the docs which built-ins a cut reaches through the launcher, so a project command at one of those names is a known override.

Twice more the same day this node lost an exit status to `| head` while trimming output for legibility -- after writing the lesson saying not to. **Writing a lesson does not install it**; every one of the three was caught by a peer or a re-read. **2026-08-25 evening adds the sub-class, from four more in one day: THREE OF THE FOUR WERE THE TOOL ERRORING RATHER THAN ANSWERING, AND THE SHAPE OF THE LOOP SWALLOWED IT.** A zsh glob erroring on a no-match `*.yaml` aborted the count and printed `workflows=0` for eleven estates; a BSD `sed` rejecting a lazy quantifier printed eleven identical error lines that were read past as data; an unquoted heredoc command-substituted a phrase out of a message. The record that was accurate was accurate BY THE ACCIDENT THAT HID THE ERROR. A digest exists to be compared in full. **The general form of both: a check whose window cannot contain the defect returns a green that means nothing, and it will do so forever.**
- **A FIX IS A CHANGE TO EVERYTHING THAT READS WHAT IT TOUCHES.** 0025 added one line to a run log and nearly sealed verdicts made of devbin's own output, because two extraction grammars print on unanchored patterns. The unguarded version passes every test anyone would think to write -- the collision needs a byte sequence nobody puts in a fixture. Before adding to an artifact, enumerate its readers.

- **A LINE-ADDRESSED EDIT VERIFIED BY READING THAT LINE BACK CANNOT SEE WHAT USED TO BE THERE, AND THE READ-BACK IS WHAT MAKES IT FEEL CHECKED.** Done to this board 2026-08-26, minutes after writing the content it destroyed: an `awk NR==39{insert}` shifted every following line by one, and the NEXT edit in the same minute still used the PRE-INSERTION numbering, so `NR==40` overwrote the just-written line instead of the intended one.

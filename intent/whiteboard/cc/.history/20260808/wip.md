**Five defects found by the preparation, four fixed the same day, each on an hv ruling, every fix red-checked:**

- **0002** (`9bf8f7a`) -- `version set` wrote the bare version over any sidecar it had no recipe for; Conflab declares two `Cargo.lock`. The composition was the sharp part: `check` says drifted -> names `sync` as the heal -> `sync` destroys the file and exits 0 -> `check` says "every sidecar agrees". The default was DOCUMENTED and TESTED (`plain.txt`), so the fix asks the FILE (`is_bare_version`, one predicate for reader and writer), not its basename -- the basename guard passes every Cargo.lock test and breaks the documented case. No `Cargo.lock` recipe on purpose: the reader (dependency-free `lib/helpers`, D15) could not follow the writer, and that asymmetry is what `lib/cmd/version:55` exists to prevent. `check` now distinguishes unreadable from drifted.
- **0005** (`d37e9e6`) -- `-x` is true for a directory, and eleven sites asked it meaning "is this a runnable handler". Lamplight keeps `lamplight_macos.d/pkg` (a directory of packaging resources) beside real sub-handlers, so `macos pkg` exec'd a directory: raw bash error, exit 126. One predicate `is_handler` (`-f` AND `-x`) at every site. The test that mattered proves a REAL sub-handler beside the directory still descends.
- **0006** (`ad1dcfe`) -- the zero-test promotion recorder was ported (named, commented, tested) and its trigger was not; `run_gate` took the tool's exit verbatim, so a tool exiting 0 having run nothing sealed EMPTY = green. Fixed per hv: `count_for` beside `grammar_for`, selected by the same `grammar:` column; `--allow-empty` opt-out. THE CORRECTION: counting off the grammar alone failed every successful compile (`check.compile` declares mix's grammar for its failure reader without being a test run) -- a counter prints a number only when the tool's TRAILER was present, and run_gate tests "a number that equals zero", never "not a number". All four counters ported from the corpus, not invented.
- **0003** (`c9f6374`) -- `check format` verified Elixir alone while `fmt` formats four languages; the test policing the pair bound it to `fmt elixir` under a name claiming the whole relationship. Fixed per hv's ruling that "nothing to format" is a legitimate outcome: `check.format` is `any` + `@builtin` shaped after `check.critic`, one arm per declared language, each arm DERIVED from its fmt row (`builtin_fmt_check_run`), markdown excluded with the exclusion proven to discriminate. AC-15.6 broadened on its face.
